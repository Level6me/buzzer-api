📌 硬件 PWM 声学原理说明

无源蜂鸣器需要交变方波驱动。本接口通过树莓派原生 SoC PWM0 通道精准生成周期信号，占空比 (Duty Cycle) 对应声音能量：

  • 1% ~ 5%: 微弱音量，声音纯净无杂音，适合夜间或办公环境。
  • 10% ~ 25%: 常用标准音量，清晰悦耳。
  • 30% 以上: 达到最大响度，但易引起簧片剧烈共振产生破音。

🔑 API 访问令牌 (Token 认证管理)

如果服务端在环境变量中配置了 BUZZER_API_TOKEN，则发声与控制接口必须附带该 Token。

💻 快速调用示例 (Curl & Python)

1. 发送单音 (Tone) 
curl -X POST http://127.0.0.1:8001/api/play/tone   -H "Content-Type: application/json"   -H "X-API-Token: YOUR_TOKEN"   -d '{"frequency": 1000, "duration": 0.2, "volume": 25}'
2. 播放预设旋律 (Melody) 
curl -X POST http://127.0.0.1:8001/api/play/melody   -H "Content-Type: application/json"   -H "X-API-Token: YOUR_TOKEN"   -d '{"name": "success", "volume": 30}'
3. 紧急静音 / 停止 (Stop) 
curl -X POST http://127.0.0.1:8001/api/stop   -H "X-API-Token: YOUR_TOKEN"
